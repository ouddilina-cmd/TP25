# TP 25 — prototype

Cette version est un prototype fonctionnel du site de classe.

## Lancer le site
1. Décompresse le dossier.
2. Ouvre `index.html` dans un navigateur moderne.

Les matières, chapitres, projets, palette et fichiers ajoutés sont conservés dans le navigateur via `localStorage`.

## Important
Le dépôt de fichiers de cette version est local au navigateur : un fichier ajouté ici n'est pas encore envoyé à Internet et n'est donc pas automatiquement visible par les autres élèves.

Pour la vraie version partagée, il faudra connecter ce même design à une base de données + stockage (par exemple Supabase ou Firebase) et ajouter des comptes/droits d'accès. Le front-end est déjà structuré pour cette évolution.

## Personnalisation
- Ajouter / modifier / supprimer des matières
- Choisir l'icône, la section et la couleur d'une matière
- Ajouter et supprimer des chapitres
- Créer des projets
- Choisir une palette globale ou une couleur personnalisée
- Rechercher dans les fichiers
